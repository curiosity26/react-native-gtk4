# @curiosity26/react-native-gtk4-safe-area-context

The Linux (GTK4) side of [`react-native-safe-area-context`](https://www.npmjs.com/package/react-native-safe-area-context) for
[@curiosity26/react-native-gtk4](https://github.com/curiosity26/react-native-gtk4):
the `RNCSafeAreaContext` TurboModule (`initialWindowMetrics`).

```sh
npm install react-native-safe-area-context @curiosity26/react-native-gtk4-safe-area-context
npx react-native run-linux
```

`run-linux` and `package-linux` autolink it. The library's own JavaScript
is unchanged. See [docs/libraries.md](../../docs/libraries.md).
