# @curiosity26/react-native-gtk4-netinfo

The Linux (GTK4) side of [`@react-native-community/netinfo`](https://www.npmjs.com/package/@react-native-community/netinfo) for
[@curiosity26/react-native-gtk4](https://github.com/curiosity26/react-native-gtk4):
the `RNCNetInfo` TurboModule, on GIO's GNetworkMonitor and NetworkManager.

```sh
npm install @react-native-community/netinfo @curiosity26/react-native-gtk4-netinfo
npx react-native run-linux
```

`run-linux` and `package-linux` autolink it. The library's own JavaScript
is unchanged. See [docs/libraries.md](../../docs/libraries.md).
