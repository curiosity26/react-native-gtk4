# @curiosity26/react-native-gtk4-vector-icons

The Linux (GTK4) side of [`@react-native-vector-icons/<family>`](https://www.npmjs.com/org/react-native-vector-icons) for
[@curiosity26/react-native-gtk4](https://github.com/curiosity26/react-native-gtk4):
the icon fonts, registered with fontconfig at startup.

```sh
npm install @react-native-vector-icons/<family> @curiosity26/react-native-gtk4-vector-icons
npx react-native run-linux
```

`run-linux` and `package-linux` autolink it. The library's own JavaScript
is unchanged. See [docs/libraries.md](../../docs/libraries.md).
